Projet Internet: Jeu de Mots

Conception et developpement d'une page web interactive autour d'un jeu de mots croises. Le projet met l'accent sur l'ergonomie, la lisibilite et la logique front-end.

Role: Front-end developer Focus: Interaction utilisateur Contexte: Projet web academique

Stack

HTML, CSS, JavaScript

UI

Responsive + Navigation claire

Logic

Validation et feedback des reponses

Elements Techniques

Implementation

Objectifs UX

  • Faciliter la saisie des mots dans la grille.
  • Afficher les definitions de facon intuitive.
  • Maintenir une experience fluide sur mobile et desktop.

Fonctionnalites

  • Grille interactive avec zones editables.
  • Systeme de verification des reponses.
  • Feedback visuel pour guider la progression.
  • Structuration modulaire des composants de page.
Ce projet montre ma capacite a transformer un besoin pedagogique en interface web claire, reactive et facilement testable.
