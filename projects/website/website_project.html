Plateforme Web pour Association Sportive

Projet complet de conception d'une application web connectee a une base relationnelle pour gerer membres, activites, inscriptions et administration interne.

Role: Full-stack et schema SQL Perimetre: CRUD + structure BDD Contexte: Projet academique

Backend

PHP 7.4+

Database

MySQL / MariaDB

Frontend

HTML, CSS, JavaScript

Architecture Technique

Data + Web

Schema relationnel

  • Table membres avec informations personnelles et statut.
  • Table activites pour les disciplines proposees.
  • Table inscriptions pour relier membres et activites.
  • Table paiements pour le suivi administratif.

Contraintes et robustesse

  • Cles primaires auto-incrementees et integrite referentielle.
  • Validation des champs sensibles (email, dates, telephone).
  • Indexation sur les colonnes de recherche recurrentes.
  • Structure preparee pour evolution fonctionnelle.

Organisation du code

  • config/ pour les connexions et parametrage.
  • includes/ pour les composants mutualises.
  • admin/ pour l'espace de pilotage interne.
  • sql/ pour l'initialisation de la base.

Valeur du projet

  • Vision de bout en bout, du schema aux ecrans utilisateurs.
  • Mise en pratique du modele relationnel dans un vrai cas.
  • Capacite a connecter front, back et base de donnees.
  • Approche structuree orientee maintainabilite.
