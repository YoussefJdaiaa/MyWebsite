Sports Association Web Platform

End-to-end web development project combining relational database modeling and a practical interface to manage members, activities, registrations and administration workflows.

Role: Full-stack + SQL modeling Scope: CRUD and data consistency Context: Academic software project

Backend

PHP 7.4+

Database

MySQL / MariaDB

Frontend

HTML, CSS, JavaScript

Technical Architecture

Data + Web

Relational schema

  • Members table for personal data and membership status.
  • Activities table for available sports and sessions.
  • Registrations table linking users and activities.
  • Payments table for financial tracking.

Data integrity

  • Auto-increment primary keys and foreign key constraints.
  • Validation for critical fields such as email and dates.
  • Indexes on frequent query paths.
  • Clean structure for future feature growth.

Code organization

  • config/ for connection and environment settings.
  • includes/ for reusable PHP components.
  • admin/ for internal management screens.
  • sql/ for schema creation scripts.

Project impact

  • Demonstrates full flow from database to user interface.
  • Applies relational modeling in a realistic product setup.
  • Connects frontend, backend and data layer coherently.
  • Built with maintainability and scalability in mind.
