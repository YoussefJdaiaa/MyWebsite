Delivery Planning Optimization

C-based algorithmic project for vehicle route optimization. The implementation follows a route-first/cluster-second logic to produce efficient tours and reduce total travel cost.

Role: Algorithm implementation Domain: Logistics optimization Language: C

Method

Route-first / Cluster-second

Core artifact

SPLIT auxiliary graph

Goal

Minimize total travel distance

Algorithm Structure

Optimization flow

Step 1: Giant tour

  • Build an initial global route over all delivery nodes.
  • Represent feasible visit ordering before clustering.
  • Create a deterministic base for route splitting.

Step 2: SPLIT graph

  • Construct an auxiliary directed graph of candidate segments.
  • Attach segment costs to encode vehicle constraints.
  • Translate routing decisions into path optimization.

Step 3: Shortest path

  • Run a shortest path procedure on SPLIT graph.
  • Recover clustered tours from selected optimal arcs.
  • Output final route set with lower operational cost.

Engineering value

  • Bridges graph theory and operational constraints.
  • Shows strong algorithm-to-code translation skills.
  • Applicable to real logistics planning scenarios.
This project is a solid proof of algorithmic reasoning under constraints, with direct relevance for route optimization and operations research use cases.
