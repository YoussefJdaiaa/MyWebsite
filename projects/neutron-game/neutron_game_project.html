Neutron Game Project

Strategy game implementation based on C game-modeling logic, then adapted into an interactive web experience. The project focuses on rule consistency, move validation and win-state control.

Role: Algorithm design + integration Core language: C UI layer: JavaScript + HTML

Game type

Two-player strategy

Main objective

Move neutron to first or last row

Key skill

Formal rule modeling

Rules and Logic

Gameplay

Winning conditions

  • Move the neutron to the top or bottom row.
  • Block the opponent from any legal move.
  • Alternate turns between red and blue pieces.

Technical aspects

  • 8-direction move validation per selected piece.
  • Auto-stop behavior at board edge or obstacle.
  • Full board state update after each turn.
  • Real-time status feedback in output console.
This project demonstrates my ability to convert abstract strategic rules into deterministic, testable software behavior.
