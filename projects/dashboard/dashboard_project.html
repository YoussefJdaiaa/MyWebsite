Electric Vehicle Dashboard

Interactive data visualization project built to explore public electric vehicle records from Washington State, with filters, summary indicators and dynamic charts.

Role: Data analyst + frontend Stack: Plotly, JavaScript, Bootstrap Dataset: Washington EV open data

Visualization

Dynamic multi-chart dashboard

Analysis

Distribution, brands, average range

Usage

Interactive trend exploration

Technical Content

Data storytelling

Dashboard focus

  • Track EV fleet growth over time.
  • Compare brand market share patterns.
  • Analyze average range across categories.

Implementation approach

  • Load and preprocess CSV-based records.
  • Create visualizations with Plotly.js.
  • Build filtering logic in JavaScript.
  • Keep the layout responsive for fast reading.
