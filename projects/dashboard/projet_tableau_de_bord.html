Tableau de Bord Vehicules Electriques

Projet de data visualisation interactif construit pour analyser des donnees publiques sur les vehicules electriques dans l'Etat de Washington, avec filtres, indicateurs et graphiques dynamiques.

Role: Data analyst + frontend Stack: Plotly, JavaScript, Bootstrap Dataset: open data Washington EV

Ce que montre le dashboard

  • Evolution du parc de vehicules electriques dans le temps.
  • Part de marche des constructeurs.
  • Comparaison des autonomies moyennes selon segments.

Approche implementation

  • Chargement et preparation des donnees depuis CSV.
  • Generation de graphiques avec Plotly.js.
  • Construction d'une interface filtree en JavaScript.
  • Mise en page responsive pour consultation rapide.
